## Tóm tắt kết quả thảo luận

- **CRUD** trả lời câu hỏi: ứng dụng *làm gì* với dữ liệu (Thêm, Xem, Sửa, Xóa).
- **API** trả lời câu hỏi: các thành phần *giao tiếp* với nhau như thế nào (request, response).
- **MVC** trả lời câu hỏi: mã nguồn được *tổ chức* ra sao (Model, View, Controller).

Ba khái niệm không thay thế nhau mà bổ sung nhau. Trong bài Quản lý Điểm:
CRUD là chức năng, các endpoint HTTP là cách giao tiếp, còn MVC là hướng tổ chức mã nguồn.
